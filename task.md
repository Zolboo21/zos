**DATA SCIENTIST TASK**

**Objective**

The goal of this task is to build a model that predicts customer behavior and activity based on the provided dataset. The task evaluates your ability to work with real-world data and deliver actionable insights.

Specifically, you are expected to analyze customer transaction patterns, identify key features, and build predictive and segmentation models. You should demonstrate your ability to handle messy data, engineer meaningful features, and clearly communicate your findings.

**Scope of the Task**

- Data preprocessing (cleaning, error checking and fixing, merging)
- Feature engineering + Feature Importance / explainability
- Time series data-based ML/AI model
- Measure and report analysis and model results

**1. Technical Requirements**

- Feature engineering (lag, rolling, seasonal effects, etc.)
- Feature Importance (SHAP/Importance, etc.)
- Time series prediction
- Customer segmentation
- Model performance measurement
- Tools to use: Python, SQL, PySpark

**2. Task Structure and Steps**

- Data cleaning + EDA
- Feature engineering + Importance
- Predictive model
- Segmentation model
- Feature analysis
- Report the results

**3. Final Deliverables**

- Model and analysis results
- Algorithms used, along with the results obtained
- Presentation

**4. Dataset**
./dataset.csv
